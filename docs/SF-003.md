# ERA × Carob schema documentation (SF-003)

**Documentation 0.1 — unpublished review candidate.** This is a knowledge
product linked to the SF-001 data-to-model pipeline in the same
[repository](https://github.com/CGIAR-AgWise/era-carob). It explains how to
interpret the schema; it is not a second software project or a released dataset.

The dictionaries were introduced by [PR #3](https://github.com/CGIAR-AgWise/era-carob/pull/3),
merged 16 November 2026 at `197ea93940cce823f36626777bd595d929f91b7b`.
They describe the corrected, pre-climate build using the ERA agronomy bundle
dated 12 May 2025 and the pinned Carob agronomy CC archive with internal files
identified by `audit/inputs.json`. Its ZIP member timestamps are
3 June 2026; these timestamps are not a verified dataset publication date. The package's Git commit identifies the documentation
edition; the archive checksums identify its underlying inputs. Preserve both.
The local `sf001-review.rds` is excluded from this documentation package.

There are 11 crop labels requiring source review and 15 vocabulary gaps.
The peach cultivar discrepancy and study-specific unit exceptions remain
visible in the dictionary and ledgers. The corrected product partition is
98 ERA-only / 52 shared / 11 Carob-only. The historical 678 figure counts
labels, not newly contributed crops. No reviewed climate-output schema or
certified model-ready dataset is included.
